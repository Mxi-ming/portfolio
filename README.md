# 小明 · 个人作品集网站

基于原生 HTML / CSS / JavaScript 构建的个人作品集单页网站，采用杂志式排版，展示个人介绍、技能方向与项目作品。

## 主要功能

- **首屏展示**：姓名、个人方向标签与关键词速览
- **项目作品**：四个代表性项目，由 JS 渲染，支持四种杂志版式（特写通栏 / 双栏交替 / 错位小图）
- **关于我**：个人简介与技能方向列表
- **联系方式**：邮箱与社交链接（深色收尾区块）
- **深浅色主题切换**：顶栏右侧按钮一键切换，`localStorage` 记忆用户选择，未选择时跟随系统偏好
- **交互细节**：滚动顶栏毛玻璃效果、导航区块高亮、移动端汉堡菜单、进场显现动效
- **响应式**：兼容桌面端与移动端

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无第三方 UI 组件库）
- CSS 自定义属性（变量）驱动的主题系统
- IntersectionObserver 实现滚动高亮与进场动效

## 运行方式

无需安装依赖，直接用浏览器打开 `index.html` 即可；或启动任意静态服务器：

```bash
# Python
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 目录结构

```
lab04/
├── index.html          # 页面结构
├── css/style.css       # 样式（含深浅色主题变量）
├── js/main.js          # 渲染与交互逻辑（含主题切换）
├── js/data.js          # 个人信息与项目数据
└── assets/images/      # 项目图片与个人标识插画（SVG）
```

## 维护指南

新增或修改项目只需编辑 [js/data.js](js/data.js)：复制一条记录、修改内容，并将 `layout` 设为 `feature` / `split-left` / `split-right` / `offset` 之一即可，页面排版与编号自动更新。
